# Hermes Agent

Hermes Agent is a privately operated AI assistant that I use to manage my own Google accounts. It runs on my VPS and can carry out requests involving Gmail, Google Drive, Google Calendar, Google Contacts, Docs, and Sheets when I authorize the relevant access and the corresponding API is available.

The Google authorization screen may request permission to read, send, and modify email; read contacts; and access files, documents, spreadsheets, and calendars. Hermes Agent uses these permissions to answer my requests and perform actions I direct. It is intended for my own accounts, including my personal and professional Google accounts, rather than for general public use.

I operate this application. Questions about its use of Google data can be sent to [gerard@paligot.com](mailto:gerard@paligot.com).
